🔄 Program & Systems Development Life Cycle (SDLC)

Methodological Execution aligned with ISDS 3107 principles
Phase 1: Requirements Gathering & Business Problem Analysis

Identified the core organizational challenge: Advendtech required a modernized digital presence to compete in the regional marketplace and needed quantitative visibility into consumer purchasing behavior to optimize inventory holding costs.

Phase 2: Architectural & Interface Design

Created wireframes and layout prototypes for both desktop and mobile viewports. Designed clean, accessible navigation hierarchies and selected responsive UI frameworks (Foundation) to guarantee fast rendering on all devices.

Phase 3: Implementation & Programming

Coded semantic HTML5 and CSS3 stylesheets for the web portal. Implemented the native iOS application following Apple Human Interface Guidelines. Cleaned raw transaction logs using Excel and prepared relational structures for visualization.

Phase 4: Verification, Quality Assurance & App Store Deployment

Tested cross-browser responsiveness across Chrome, Safari, Firefox, and mobile Safari. Validated mobile app performance and successfully fulfilled Apple App Store review and publishing guidelines.

Phase 5: Business Intelligence & Strategic Decision-Making

Developed Tableau dashboards highlighting the top 20% of inventory generating 80% of sales volume. Exported actionable presentations (Tableau PowerPoint 1 & 2) directly supporting procurement decisions.
